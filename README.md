# HR Hospital Module

HR Hospital is a training module for Odoo 19.0

The module implements a basic hospital management system for working with doctors, patients, diseases and patient appointments.

## Features

- Doctors management
- Patients management
- Diseases management
- Patient appointments management
- Doctor PDF report with visit history and patient list
- Improved doctor kanban view with interns and quick actions
- Basic master data
- Demo data

## Technical information

- Odoo version: 19.0
- Module name: hr_hospital
- Language: Python
- Framework: Odoo ORM

## Installation


Copy the module to the custom addons directory as hr_hospital, update the apps list and install the HR Hospital module.
